# div16

A Minecraft coordinate calculator by **senzdev**.

Enter X and Z, optionally Y, to find the nearest multiples of 16 and the exact result of dividing each axis by 16.

- Positive, negative, and decimal coordinates
- Optional Y coordinate
- Closest coordinates with clipboard copying
- Responsive Minecraft-inspired interface
- Runs entirely in your browser

Open `index.html` locally to use the calculator offline. Ties between multiples of 16 choose the one closer to zero.
